## 下载与使用

[下载 Windows x64 便携版](https://github.com/xiaobu354-collab/abu-pomodoro/releases/latest)。完整解压后运行，无需安装。

完整解压 Windows x64 压缩包到固定文件夹，打开 `MintPomodoro-CloudTrial.exe`。这是保留的兼容文件名，界面名称仍为“阿不番茄钟”。不要只复制 `.exe`，运行时和许可文件需要一同保留。

- 默认专注 **25 分钟**、短休息 **5 分钟**、长休息 **10 分钟**；每 4 次专注安排长休息，进度按当天计算。
- **自动开始休息、自动开始专注均默认关闭**，完成阶段后可手动开始下一阶段。
- **开机自动启动默认开启**：程序会尝试设置 Windows 登录后自动打开。不需要时，点击齿轮 → 设置 → 偏好 → 关闭“开机自动启动”。移动程序文件夹后请重新打开一次，以更新启动路径。
- 鼠标移入悬浮条显示操作按钮；拖动小人区域移动。误重置或跳过后，可在 5 秒内撤销。
- 隐藏到托盘不会退出；彻底关闭请使用悬浮条或托盘菜单中的“退出”。
