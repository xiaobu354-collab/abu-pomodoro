# 阿不番茄钟 1.0.38

Windows x64 正式版及对应源码。以下为自 1.0.33 以来的累计变化；Electron 运行时仍为 **43.8.1**，十套主题图片素材未修改。不包含早期半成品、私人资料或旧版开发历史。

## 本次变化

- **跨日启动重置**：重新打开时，若已进入新的一天，清除上一天的计时会话并重置今日计数，保留个人设置和主题。
- **休息操作集中**：休息中的中央卡片提供“暂停 / 跳过休息 / 收起”，收起后仍保留迷你条。
- **完成提醒更紧凑**：专注完成卡片的“休息 / 跳过 / 2 分钟后提醒”三个按钮同排显示。
- **迷你撤销优先**：5 秒撤销窗口内，撤销图标内嵌替换“专注 / 休息”文字，不切换四按钮；点击撤销或到期后恢复正常悬停，原按钮位置和尺寸不变。
- **卡片位置稳定**：“已跳过”状态和撤销入口的显示、隐藏不再改变卡片主体位置。

## 下载与升级

[下载 Windows x64 便携版](https://github.com/xiaobu354-collab/abu-pomodoro/releases/latest)。完整解压到固定文件夹，再打开 `MintPomodoro-CloudTrial.exe`；这是保留的兼容文件名，界面名称仍为“阿不番茄钟”。不要单独复制 `.exe`，运行时和随附许可文件需要一起保留。

- 升级前请从悬浮条或系统托盘菜单中**退出旧版**；隐藏到托盘不等于退出。然后完整解压并打开新版。
- 设置保存在 `%APPDATA%\MintPomodoro-CloudPairedTrial\preferences.json`。保留该目录可沿用设置，建议升级前备份此文件；不要将自己的设置文件作为公开附件分享。
- **开机自动启动默认开启**。不需要时，到设置 → 偏好中关闭；如果移动了程序文件夹，请重新打开一次并检查开机启动设置。
- 默认专注 / 短休息 / 长休息为 **25 / 5 / 10 分钟**；自动开始休息和自动开始专注默认均关闭。
